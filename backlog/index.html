    Backlog¶

    Open work, mostly UI, that is not covered by an ADR or a PR yet. One line per item, newest requests at the top of each section; delete a line when its PR merges (the git history keeps it). Larger subsystems (library, Bluetooth stages, final board) live in their ADRs and are only pointed at here.

    Columns: Source is where the item comes from (spec = UI mock-ups, req = Stuart's request with the date, bench = seen on the testbed). Needs is what blocks it, if anything.

    Platform note (12 Nov 2026, ADR-0001 amendment): the Pico 2 W build is frozen as a compile check; items may assume the RP2350B with PSRAM and be compiled out of the Pico 2 W build.
