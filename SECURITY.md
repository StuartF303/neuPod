# Security policy

neuPod is pre-release hobby firmware; there are no supported releases yet.

If you find a vulnerability (e.g. in the Wi-Fi, Bluetooth or USB stacks as integrated here),
please report it privately via GitHub's
[private vulnerability reporting](https://github.com/StuartF303/neuPod/security/advisories/new)
rather than a public issue. Expect an acknowledgement within 14 days.
