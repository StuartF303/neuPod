    Progress: UI styles (Classic and Modern)¶

    The checklist for IMPLEMENTATION-BRIEF.md. Tick an item when its PR merges and add the PR number and date: - [x] item (#123, 2026-12-01). Mark a blocked item BLOCKED: reason and leave it unticked.
